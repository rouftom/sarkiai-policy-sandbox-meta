# Support

## Where to ask

- **Bug or regression:** open a [bug report](https://github.com/rouftom/sarkiai-policy-sandbox-meta/issues/new?template=bug_report.yml).
- **Feature or corpus addition:** open a [feature request](https://github.com/rouftom/sarkiai-policy-sandbox-meta/issues/new?template=feature_request.yml).
- **Accessibility barrier:** use the [accessibility issue template](https://github.com/rouftom/sarkiai-policy-sandbox-meta/issues/new?template=accessibility.yml); see [ACCESSIBILITY.md](ACCESSIBILITY.md).
- **Security vulnerability:** report it privately, never in a public issue; see [SECURITY.md](SECURITY.md).
- **Setup, branch model and checks:** read [CONTRIBUTING.md](CONTRIBUTING.md), then open a pull request.

Search existing issues before filing a new one. Redact secrets, tokens, cookies,
connection strings and personal data from logs, screenshots and descriptions.

## What this project supports

Support covers the source in this repository and the documented deployment
paths. It does not cover:

- custom forks or modified deployments;
- defects in third-party model providers or hosted infrastructure;
- help with a corpus document's legal status beyond the project's documented
  position in [docs/LICENSING.md](docs/LICENSING.md).

Maintainers answer on a best-effort basis. There is no paid support contract and
no service-level agreement.
